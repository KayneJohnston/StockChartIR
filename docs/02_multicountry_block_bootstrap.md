## 1. Why a multi-country bootstrap

A lifecycle study needs many independent 68-year return paths. History
supplies one. The usual fix -- resample the US series -- inherits the single
most favourable equity history in the developed world, and every conclusion
drawn from it is conditioned on that outcome having happened. Anarkulova,
Cederburg and O'Doherty's contribution is to draw the *whole panel* instead,
so a simulated investor might live through Japan's 1990s, Portugal's century,
or Italy's wars with the same probability the data assign to the US.

The engine here reproduces that scheme with two properties that are easy to
lose in implementation.

**Blocks are calendar-joint.** A draw is a *(country, calendar window)* pair,
not five independent series draws. Because `dom_eq`, `intl_eq`, `bond`, `bill`
and `inflation` are all indexed by the same calendar year in the panel, one
draw carries the contemporaneous cross-asset covariance *and* the
cross-country covariance embedded in the international leg. Nothing is
re-drawn independently, so nothing decorrelates.

**Blocks never span a data gap.** Market closures leave holes in the panel
(Germany 1944-49, France 1915-21, Spain 1936-40). A block is admissible only
if the domestic country has an unbroken run of observations covering the whole
window, which is the paper's "continuous available sub-periods" protocol.
Implementation: `run_lengths(available)[t, c]` gives the number of consecutive
usable years from `t` in country `c`, and the admissibility test is simply
`run_lengths[t, c] >= L`.

## 2. Algorithm

```
for each simulated lifetime n = 1 .. N:
    c  <- domestic country, drawn with probability p_c            (section 3.2)
    h  <- 0
    while h < H:                                                  (H = 68 years)
        L  <- block length, Geometric(1 / 10),
              clipped to [1, 40] and to the longest
              unbroken run country c can supply
        t0 <- uniform over  { t : available[t : t+L, c] all true }
        copy calendar years t0 .. t0+L-1 of country c into the path
        h  <- h + L
```

The stationary bootstrap of Politis and Romano (1994) is the default: geometric
block lengths keep the resampled process stationary, which fixed-length blocks
do not. `bootstrap.block_length_distribution: fixed` selects the classical
overlapping-block alternative.

### 2.1 Implementation notes

`BlockIndex` pre-enumerates, for every `(country, length)` pair, the sorted
array of admissible start years, flattened into one vector with an
`(offset, count)` address table. Drawing millions of admissible starts is then
pure fancy indexing rather than rejection sampling, which is why 100,000
lifetimes cost a second or two rather than minutes.

Block draws are generated per path in a vectorised sweep over the horizon:
paths whose current block has run out draw a new one simultaneously. Chunk
generators are spawned as children of one root `SeedSequence`, so the
reproducibility contract is `(seed, n_paths, chunk_size)`: rerunning with all
three unchanged reproduces the draws exactly, while changing `chunk_size`
re-cuts the random stream into a different -- equally valid -- sample. That is
why `chunk_size` lives in `config.yaml` rather than being a free performance
knob.

### 3.1 `per_lifetime` versus `per_block`

Under `per_lifetime` an investor is born into one country and stays there;
under `per_block` the domestic market is redrawn at every block boundary,
which is closer to ACO's own pooled country-time resampling. `per_lifetime` is
the headline specification because it matches the economic object of interest
-- an investor who does not emigrate every decade -- and because it produces
*wider* dispersion in lifetime outcomes, which is the conservative choice.
Section 6 reports the `per_block` variant.

### 3.2 Why the domestic country draw is history-weighted

A uniform draw over 38 countries gives Slovenia's 30 observed years the same
weight as the United Kingdom's 131. Worse, in this panel the
short-history countries are Tier-B synthetics whose windows fall in a strong
era for the world equity factor, so uniform weighting silently tilts the
answer *toward* equities -- the very direction the headline result runs, which
would make the result an artefact of the weighting scheme.

Weighting the country draw by usable country-years is both the neutral choice
and the one implied by ACO's pooling of country-time blocks. Section 6 reports
the uniform-weighting variant so the reader can see the size of the effect.

Among the four **asset return** series the largest absolute discrepancy is

on: a bootstrap that decorrelated equity from bonds would flatter every
fixed-income strategy.

Discrepancies involving the **inflation** row are larger -- up to 0.123 --
and that is a property of the series, not of the sampler. Panel inflation has
an excess kurtosis of 1,879, driven by a handful of hyperinflation
country-years (Austria 1922, Germany 1922, Japan 1945, Greece 1946). Second
moments of a distribution that fat are dominated by whether a few individual
observations happen to be drawn, so any correlation involving inflation is
unstable at this sample size. It does not affect the lifecycle results:
the engine works entirely in real terms, so inflation enters the simulation
only through the real returns that were already deflated by it.

| 10.0000 | 0.0427 | 0.0401 | -0.0201 | 0.0954 | 0.0459 |
| 20.0000 | 0.0427 | 0.0388 | -0.0188 | 0.0934 | 0.0566 |

The AR(1) column behaves exactly as designed: at a one-year block the sampler
degenerates to an i.i.d. bootstrap and within-path persistence vanishes, while
longer blocks transmit progressively more of the panel's own persistence.

The dispersion columns are the more interesting result, and they do **not**
show what a naive reading would predict. Annual real equity returns carry very
little autocorrelation to begin with, so lengthening blocks moves the spread of
68-year annualised outcomes only slightly -- and it moves it *down*, not up.
That is the long-horizon mean-reversion result showing through: preserving the
multi-year dependence in the data makes lifetime outcomes marginally *less*
dispersed than shuffling years independently would imply. The effect is small,
and the practical consequence is that the headline results are insensitive to
the block-length choice over any plausible range. The 10-year default is kept
because it matches ACO's 120-month specification, not because the answer hinges
on it.
