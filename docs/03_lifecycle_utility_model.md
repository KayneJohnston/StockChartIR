## 2. State transition

Contributions and withdrawals occur at the *start* of the year and are exposed
to that year's portfolio return:

```
W_0 = 0

working    h < 38:   W_(h+1) = (W_h + s * Y_h)  * (1 + Rp_h)
retired    h >= 38:  W_(h+1) = (W_h - X_h)      * (1 + Rp_h)

bequest              B = W_H
```

with the rebalanced real portfolio return

```
Rp_h = w_h[dom_eq] * R_h[dom_eq] + w_h[intl_eq] * R_h[intl_eq]
     + w_h[bond]   * R_h[bond]   + w_h[bill]    * R_h[bill]
```

Target weights `w_h` are restored every year (`lifecycle.rebalancing: annual`),
so `Rp_h` is a weighted average of the four real asset returns drawn by the
bootstrap for that path-year.

## 3. Labour income

Real labour income over the working years is a deterministic hump multiplied
by a permanent and a transitory shock:

```
log Yhat_h = log Y0 + b1 * h + b2 * h^2          b1 = 0.045, b2 = -0.0009
P_h        = exp( sum_{k<=h} eta_k )             eta ~ N(-sd^2/2, sd^2), sd = 0.1
T_h        = exp( eps_h )                        eps ~ N(-sd^2/2, sd^2), sd = 0.25
Y_h        = Yhat_h * P_h * T_h
```

Both shocks are normalised to unit mean, so adding income risk does not shift
the *level* of the profile. The quadratic peaks at age
50 at
1.76x
starting income, the standard Cocco-Gomes-Maenhout shape.

**Income realisations are drawn once per path and shared across every
strategy.** Without that, cross-strategy differences would be contaminated by
income noise rather than reflecting portfolio choice.

### 3.1 A stated limitation

Labour income here is idiosyncratic: it is not linked to the drawn country's
macroeconomy, so a simulated investor who lives through Germany's 1920s keeps
drawing a normal wage path. ACO tie labour income to the sampled country. The
omission biases *against* the paper's conclusion -- correlating wage disasters
with equity disasters would make equity look riskier, not safer -- so the
headline finding is not manufactured by it.

## 4. Social security

The benefit is computed from career-average real earnings `AIME = mean_h Y_h`
using the US primary-insurance-amount bend-point schedule
(`lifecycle.social_security.formula: progressive`):

```
PIA = 0.9 * min(AIME, b1)
    + 0.32 * clip(AIME - b1, 0, b2 - b1)
    + 0.15 * max(AIME - b2, 0)

b1 = 0.21 * Ybar,   b2 = 1.28 * Ybar
```

where `Ybar` is economy-wide average real earnings. The progressive schedule
matters more than it looks: the 90% first tranche puts a genuine **real
consumption floor** under investors who drew a bad sequence of labour-income
shocks. Without it, high-risk-aversion certainty equivalents are driven
entirely by the left tail of the income process and stop discriminating
between portfolios at all.

## 5. Drawdown algorithm

`lifecycle.retirement.rule: fixed_real_rule` with rate
0.04.

```
X_target = rule_rate * W_retire                 # fixed in REAL terms
for h in retirement years:
    X_h = min(X_target, max(W_h, 0))
    if X_h < X_target and not already ruined:
        record ruin at age (age_start + h)
    C_h = PIA + X_h
    W_(h+1) = max(W_h - X_h, 0) * (1 + Rp_h)
```

This is the "4% rule": a real withdrawal fixed at retirement and held constant
in purchasing power, which is why it can fail. **Ruin** means financial wealth
is exhausted before age 93; consumption then falls to social security alone,
which is a large but not catastrophic drop. `fixed_percentage` is available as
a proportional alternative that mechanically cannot ruin.

## 7. Preferences

Let `C_n = (C_n1, ..., C_nT)` be path `n`'s real consumption over the dates in
the evaluation window and `B_n` its bequest.

### 7.1 Evaluation window

`utility.consumption_window: retirement`. With a fixed savings rate,
working-life consumption is `(1 - s) * Y_h` on *every* strategy, so including
it adds a large strategy-invariant term that compresses every certainty
equivalent toward a common value -- at gamma = 10 it flattens the ranking
entirely. The reported basis is therefore retirement consumption plus the
bequest, which is also ACO's reporting basis. Re-indexing the window to start
at `h = 0` rescales `E[U]` and the weight total by the same `beta^38`, so the
certainty equivalent is unaffected.

### 7.2 CRRA

```
u(c)  = c^(1-gamma) / (1-gamma)        (log c when gamma = 1)

U_n   = sum_h beta^h u(C_nh)  +  theta * beta^T * u(kappa + B_n)

D     = sum_h beta^h  +  theta * beta^T

CEC   = ( (1-gamma) * E[U] / D )^(1/(1-gamma))
```

with `beta = 0.96`, `theta = 2`, and risk aversions
gamma in {2, 5, 10}.

**Certainty equivalent consumption** is the constant real stream that leaves
the investor exactly as well off as the risky strategy. It is reported instead
of raw expected utility because raw `E[U]` is not comparable across gamma; CEC
is always in consumption units.

### 7.3 The bequest shift `kappa`

`kappa = 1` is the De Nardi (2004) "bequests are a luxury good"
shift: the bequest enters as `kappa + B`, not `B`. Without it, `u(0) = -inf`
for every `gamma >= 1`, one ruined path drives the certainty equivalent of
*every* strategy to zero, and the metric stops discriminating. A certain
stream `c` paired with `B = c - kappa` returns `CEC = c` exactly, so the units
stay interpretable.

### 7.4 Epstein-Zin

Recursive Epstein-Zin-Weil preferences separate the two roles CRRA conflates:
`psi` governs substitution across *time*, `gamma` governs aversion to risk
across *states*. Evaluating the full recursion path-by-path needs conditional
continuation values, which a state-free bootstrap cannot identify, so this
implementation uses the **ex-ante (early-resolution)** form:

```
step 1, time aggregation (CES in psi):
    Chat_n = [ sum_h beta^h C_nh^(1-1/psi) / D ]^(1/(1-1/psi))

step 2, risk aggregation (CRRA in gamma):
    CE     = ( E[ Chat^(1-gamma) ] )^(1/(1-gamma))
```

IES values evaluated: psi in {0.5, 1.5}.

**What this assumes.** All uncertainty is treated as resolving at date 0.
Genuine recursive Epstein-Zin cares about *when* uncertainty resolves, and
this form does not. The specification nests time-additive CRRA exactly when
`psi = 1/gamma` -- asserted in `tests/test_utility.py::test_epstein_zin_nests_crra`
-- so the two families are on a common footing, and the comparison across
strategies is like-for-like even though the level is not the full recursive
utility.

### 7.5 Shortfall and ruin metrics

| Metric | Definition |
| --- | --- |
| `prob_ruin` | P(financial wealth exhausted before age 93) |
| `p5_bequest` | 5th percentile of real terminal wealth |
| `median_wealth_at_retirement` | median `W` at age 63 |
| `median_retirement_consumption` | median real consumption over retirement |
| `prob_consumption_below_target` | P(mean retirement consumption < target) |
| `mean_consumption_shortfall` | `E[max(target - path mean, 0)]` |
| `p5_consumption_replacement_ratio` | 5th percentile of (retirement consumption / target) |

The **target** is strategy-invariant by construction: a fixed replacement
rate on the investor's *own* career-average real earnings, shared across
strategies because labour income is drawn once per path. Measuring each
strategy against its own median -- the tempting shortcut -- makes every
strategy look identical and destroys the comparison.

## 8. Units

Everything is scaled to **multiples of initial (age-25) annual real income**.
A median bequest of 30 means thirty years of a 25-year-old's salary, in that
25-year-old's purchasing power.
